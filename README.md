(ignore steps 1 & 2 for windows)


1. Ensure you aren't running on headless Java in linux
2. Ensure you have your correct display set in linux
3. Ensure you have dependencies, including maven installed
4. cd into RevTacToe
5. run 'mvn clean compile'
6. WINDOWS run 'mvn exec:java'
7. LINUX run 'java -cp target/classes Main'
8. To run test class run 'mvn test'
